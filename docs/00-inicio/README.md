## ¿Cómo estudiar un tema?
Cuando leas sobre una herramienta, siempre pregúntate:
1. **¿Qué es?** (El concepto).
2. **¿Por qué lo necesitamos en FOTON-IA?** (El problema que resuelve).
3. **¿Cómo participa en la Alta Disponibilidad?** (Qué pasa si algo falla).

Cada tema individual (una tecnología concreta, como PostgreSQL o Keepalived) debe documentarse siguiendo **[la Plantilla Estándar de 18 puntos](../PLANTILLA.md)**. Los módulos que agrupan varias tecnologías (06, 07, 08, 09) tienen un `README.md` de índice y un archivo `.md` por tecnología, cada uno con sus 18 puntos completos.
