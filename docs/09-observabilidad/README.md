# 📊 Módulo 09: Observabilidad (Prometheus y Grafana)

Sin observabilidad, un failover puede ocurrir sin que nadie se entere hasta que un sensor deja de reportar. Este módulo cubre las dos herramientas que corren en VM3:

1. [Prometheus](./prometheus.md) — recolecta métricas de todos los nodos y servicios.
2. [Grafana](./grafana.md) — las visualiza en dashboards.

➡️ Empieza por **[Prometheus](./prometheus.md)**.
