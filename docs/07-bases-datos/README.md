# 🗄️ Módulo 07: Bases de Datos (PostgreSQL y Redis)

Este módulo cubre las dos bases de datos del clúster. Ambas se replican de VM1 hacia VM2 para que la Alta Disponibilidad funcione:

1. [PostgreSQL](./postgresql.md) — la base de datos principal donde se guarda la telemetría histórica.
2. [Redis](./redis.md) — la caché en memoria para datos de acceso rápido (últimas lecturas, sesiones).

➡️ Empieza por **[PostgreSQL](./postgresql.md)**.
